# Benchmark report

Generated by `npm run bench` (design section 11). Method: local Docker, warm cache, 50 warm-up requests discarded, 500 measured requests per case, concurrency 1 and 8, percentiles from `simple-statistics` (p95 by linear interpolation). Docker was given 8 CPUs, 7.7 GiB memory. Sort memory is at its default. Context: most-trained exercise "bench press", rarely logged exercise "farmer carry", least-trained group "calves".

**The budgets are checked on the p95 at concurrency 1 only** (the owner's decision); the concurrency 8 figures are reported, not gated. Times are wall-clock over HTTP, body included.

The compare plan below is for one period's statement; over HTTP the API runs two PR statements plus up to six primary-key loads in one transaction, so its HTTP time covers both periods.
